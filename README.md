# 今日老婆 Pro+ (partner-game)

> **本项目是 [onelxzy/partner-game](https://github.com/onelxzy/partner-game) 的维护分支（fork）**，
> 由 [tianditongcuo](https://github.com/tianditongcuo) 维护，插件 ID 为
> `tianditongcuo.partner-game-pro`，可与原版 `onelxzy.partner-game` 区分安装。
> 原项目基于 [whitefox 的 wife_picker](https://github.com/whitefox20011120/wife_picker) 的基础逻辑扩展开发。

一个跑在 MaiBot 群聊里的**修仙 RPG 伴侣大乱斗**：抽伴侣、结婚、打工赚钱、修仙突破，
也可以化身黄毛去抢别人的伴侣、打劫、霸凌甚至镇压。

## 🎮 六大系统

### 💞 婚姻
`/今日老婆` 随机抽一位伴侣（抽到即绑定），`/娶` 求婚需对方在 60 秒内回「我同意」，
`/离婚` / `/甩掉` 解除关系。伴侣可 `/约会` 提升好感。

### ⚔️ 犯罪
- `/强娶` —— 概率硬绑单身者，失败罚款
- `/抢老婆` —— 抢别人的伴侣，受**战力差**与**好感护盾**影响
- `/打劫` —— 抢金币，可以把人打成负债
- `/霸凌` —— 需高 2 个大境界：抢钱 + 封禁对方行动
- `/镇压` —— 需高 4 个大境界：封禁对方与其伴侣，并打落夫妻二人修为

### 💰 经济
初始 1000 金币，每周期首次互动发低保。`/打工` 收益 = `-100 ~ 等级×1000`（**可能倒贴**），
`/修炼` 花金币突破，`/送钱` 与 `/上交存款` 互相转账，`/氪金` 用金币为下一次行动积攒好运（概率可叠到 100%，即必定成功）。

> ⚡ **雷劫**：修到**元婴**之后，每次尝试大境界突破都会引来雷劫——本次突破直接失败、修为跌落。
> 触发概率、起始境界、跌落层数都在 WebUI「③ 修炼与氪金」里可调；带氪金加成的这次突破会按加成值降低雷劫概率。

### 🌌 天道
- `/下秘境` —— 金币 / 修为暴涨 / 修为倒退 / 陨落
- `/打怪` —— 金币 / 修为提升 / 境界跌落 / 陨落
- `/贷款` 借钱（额度 = 境界等级 × 1000，须还 2 倍，15 分钟逾期封禁行动）、`/还贷` 一次性结清
- `/重生` —— 直接回到最初状态（修为归零、金币复原，可在 WebUI 调保留比例），陨落时自动触发
- `/成圣` —— 散尽**全部**金币，按身家尽量连升、无视大小境界（默认最高 99 层）；但有几率遭天谴，反而跌落

### 💕 夫妻
好感满 100 后可 `/申请交配`，对方回复「同意」即可，双方获得大量好感。

### ⚡ 天道惩戒
- **天妒**：一周期修炼成功 6 次 → 修为倒退
- **天罚**：一周期犯罪超过 8 次 → 扣除 60% 金币
- 两者都是「每周期一次」，且**触发概率可调**

## 📦 安装

### 方式一：插件市场（推荐）
MaiBot WebUI → 插件页 → 搜索「今日老婆 Pro+」→ 安装。

### 方式二：手动安装
把本仓库内容放进 `plugins/<任意名>/`，确保 `_manifest.json` 直接位于该目录根下：

```
plugins/
└── tianditongcuo_partner-game-pro/
    ├── _manifest.json
    ├── plugin.py
    └── ...
```

> ⚠️ 从 GitHub 下载 zip 解压后常多套一层目录，必须把内容**平铺**到插件根目录。
> ⚠️ 同一插件 ID 只能存在一份目录，否则 MaiBot 会报「插件 ID 重复，已阻止加载」。

## ⚙️ 配置

配置分两层：

| 层 | 位置 | 内容 |
|---|---|---|
| 插件参数 | WebUI → 插件配置 → 今日老婆 Pro+ | 候选池、管理员、三种基础概率、冷却 |
| 数值平衡 | 同上，§① ~ §⑮ | 120+ 个可调数值，覆盖次数、门槛、罚款、概率、周期、缓存 |

数值平衡分组：

| 组 | 内容 |
|---|---|
| ① 周期与次数 | 周期时长 + 各类次数（可填「不限制」或 0） |
| ② 金币与打工 | 初始金币、低保、打工收益、约会 |
| ③ 修炼与氪金 | 修炼费用与成功率、氪金换算、雷劫 |
| ④ 婚姻与冷却 | 抽取/离婚/求婚/甩人的冷却、离婚惩罚开关 |
| ⑤ 强娶 | 门槛、罚款上下限、冷却 |
| ⑥ 抢老婆 | 门槛、罚款、掉级率、冷却 |
| ⑦ 打劫 | 周期、门槛、劫掠上限、罚款、冷却 |
| ⑧ 好感与交配 | 护盾档位/效率/硬上限、交配参数 |
| ⑨ 下秘境 | 周期、金币系数、暴涨/倒退级数、概率 |
| ⑩ 贷款 | 还款倍数、时限、每级贷款额度 |
| ⑪ 天道惩戒 | 天妒/天罚的阈值、概率、惩罚强度、陨落、重生保留比例与重生金币 |
| ⑫ 打怪 | 次数、金币、升降级、四种概率 |
| ⑬ 霸凌 | 周期、冷却、次数、境界差、封禁时长、成功率、赔付与抢夺区间 |
| ⑭ 镇压 | 同上 + 伴侣封禁时长、跌落级数 |
| ⑮ 性能 | 成员列表缓存、头像缓存 |
| ⑯ 贷款成圣 | 成圣最高等级、每层价格与加价、天谴概率与跌落层数、周期与次数 |

> 所有数值留空等于用 `balance.py` 里的出厂默认值；改完保存即热重载生效。
> 另有 `docs/tuning.html`：拖动滑块实时预览曲线，一键导出可粘贴的常量片段。

## 🛠 维护与开发

`docs/` 里有一套自动生成 + 自检工具：

```bash
python docs/tools/gen_maintenance_map.py   # 扫描源码 → 功能/依赖地图
python docs/tools/gen_dashboard.py         # 渲染可视化面板 dashboard.html
python docs/tools/gen_tuning.py            # 生成可交互调参面板 tuning.html
python docs/tools/smoke_test.py            # 冒烟测试（导入/实例化/纯函数）
python docs/tools/test_rules.py            # 业务规则测试
python docs/tools/test_handlers.py         # handler 级测试（真跑成功/失败分支）
python docs/tools/verify_plugin.py . <plugins目录>      # 插件识别预检
python docs/tools/deploy.py --plugins-dir <plugins目录> # 一键部署
python docs/tools/sync_config.py --config <插件目录>/config.toml  # 升级后补齐新字段（保留你改过的值）
```

> `check_config.py` 需要用 MaiBot 自带的 Python 运行（依赖 pydantic + maibot_sdk），
> 它会校验「每个默认值是否落在自己的区间内」——这是 WebUI 保存失败的高发原因。

## ❓ 常见问题

**装完没反应？**
看日志有没有 `插件 ID 重复，已阻止加载` —— 说明装了两份，删掉多余的。

**WebUI 里改了保存失败？**
多半是某个字段的区间/类型冲突。用 `docs/tools/check_config.py` 自检。

**为什么我的钱变少了？**
`/打工` 的收益下限是负数，可能亏本；另外天罚、罚款、被打劫都会扣钱。

**被封锁了怎么办？**
贷款逾期或被人霸凌/镇压时会封锁行动。贷款逾期用 `/还贷` 解除，霸凌/镇压等封禁时长过去。
